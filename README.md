# Поясни слово

Командна гра онлайн для компанії: кожен грає зі свого телефона чи компʼютера в одній віртуальній кімнаті.
Встановлюється як застосунок (PWA).

**Грати:** https://spivakandrii.github.io/poyasny/

## Як грати

1. Усі збираються в голосовому дзвінку (Discord, Zoom, Meet).
2. Кожен відкриває гру і вводить своє імʼя та **однакові** назву кімнати і пароль.
   Хто зайшов першим, той ведучий (★): налаштовує гру і натискає «Почати гру».
3. Гравці розходяться по командах (щонайменше двоє в кожній).
4. Пояснювач бачить слово і пояснює його голосом, не називаючи слова і спільнокореневих.
   Його команда вгадує, суперники слухають (слова їм не видно).
5. Коли час вийшов, останнє слово може вгадати будь-яка команда, тож його бачить лише пояснювач.
6. Після раунду всі бачать список слів, а пояснювач може виправити позначки, якщо суперники помітили нечесне пояснення.
7. Перемагає команда, яка першою набрала потрібну кількість очок (після повного кола ходів).

## Як це влаштовано

Чистий HTML, CSS і JavaScript на GitHub Pages, без власного сервера.

| Файл | Що робить |
|---|---|
| `net.js` | кімната: шифровані повідомлення через публічні MQTT-брокери |
| `app.js` | ведучий, ролі гравців, таймер, рахунок, екрани |
| `words.js` | набори слів «Загальні» і «Айті» |
| `manifest.webmanifest`, `sw.js` | встановлення як застосунку |

**Звʼязок.** Повідомлення йдуть через безкоштовні публічні MQTT-брокери (EMQX і HiveMQ) по WebSocket.
Гра підключається до обох: якщо один недоступний, працює другий.

**Приватність.** Назва кімнати і пароль перетворюються на адресу (SHA-256) і ключ шифрування (PBKDF2 → AES-GCM).
Брокер бачить лише зашифровані байти, пароль нікуди не надсилається.

**Ведучий.** Перший гравець у кімнаті тримає стан гри і розсилає його всім кожні 2 секунди.
Якщо ведучий вийшов, його роль за ~10 секунд переходить до іншого гравця, гра триває.

## Запуск локально

```powershell
npx http-server . -p 8082
```

Відкрити http://localhost:8082 у кількох вкладках: кожна вкладка — окремий гравець.

## Ідеї для лабораторних

1. Свій набір слів (додати ключ у `DECKS` у `words.js`).
2. Рахунок по кожному гравцю: хто найкраще пояснює.
3. Режим «покажи жестами» або «намалюй» для третьої команди.
4. Чат у кімнаті для тих, хто без мікрофона.
